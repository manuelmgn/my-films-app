# Filmapp

Filmapp is a React application that allows users to discover popular films, search for specific titles, view detailed information, and maintain a personal list of rated movies.

Built using React and TypeScript, and styled with Tailwind CSS.

## Technologies

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Heroicons
- React Router 7
- Context API
- useReducer
- Local Storage
- TMDB API

## Installation

```bash
# Clone the repository
git clone https://github.com/manuelmgn/my-films-app.git

# Navigate to project directory
cd my-films-app

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building and Deployment

The app is configured for deployment on GitHub Pages:

```bash
# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
